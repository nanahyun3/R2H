## 3. 비교 가능 / 불가 목록

### 3.1 비교 가능 (조건부)

| # | 비교 | 조건 |
|---|---|---|
| P-1 | base 정책의 연도별 사후 T·기각 | 같은 계산이다 (§2). 독립 재현의 증거로만 쓴다. T12 의 새 결과로 세지 않는다 |
| P-2 | 같은 날짜 구간에서 일별 예측분산 손실 (QLIKE) — T11 고정 모형 vs T12 연초 모형 | 같은 날짜 집합 (예: 2024-05-29 이후) 에서, 같은 정의로 다시 계산한 경우만. T11 은 일별 예측을 커밋하지 않았으므로 지금은 **실측 없음** |
| P-3 | 이동창 통계량의 **식** (`rolling_cusum`) 과 점별 임계값의 **정의** | 같은 함수다. 그러나 풀이 다르므로 임계값 **값**은 비교 대상이 아니다 |
| P-4 | 연도별 RV (V 축) | 모형과 무관한 사후 기술값이다. T11 노트북의 고변동 해와 같은 자료로 계산한다 |

### 3.2 비교 불가

| # | 비교 | 이유 |
|---|---|---|
| N-1 | T11 사후 검정 기각 수 (A 2/20 · B 9/20 · base 1/20) vs T12 연간 기각 수 | n 이 다르다 (571 vs 184–248). 검정 구간이 다르다 (2.3년 한 구간 vs 달력연도). 모형 나이도 다르다. CUSUM 은 구간 안의 e² 수준 변화에 반응하므로, 구간이 길면 연도 사이의 변화까지 잡는다. 따라서 같은 귀무를 검정하지 않는다 |
| N-2 | T11 `yearly_blocks` (svrA) vs T12 `annual_posthoc` (A) | T11 의 2019–2023 블록은 적합 구간 in-sample 이다 (`SPEC B§7` 금지). 2024 블록도 분할일(2024-05-29) 전후가 섞인다. T11 A 의 연도 블록 기각 (2020 1 · 2022 1) 과 T12 A (2020 11 · 2022 0) 의 차이는 "expanding 의 효과" 가 아니다. in-sample vs OOS, 모형 1개 vs 7개가 섞여 있다 |
| N-3 | T11 `null_episodes_per_year` vs T12 `expected_null_episodes` | 단위가 다르다 (연율 vs 연간 원카운트). 길이·마스크·반복 수도 다르다 (1,902·없음·100 vs n_days·PURE·200) |
| N-4 | T11 `c_bootstrap` vs T12 `pointwise_null_quantile` | 풀이 다르다 (T11 적합 구간 1,331개 in-sample vs T12 매년 다른 사전 연도 풀) |
| N-5 | T11 경보 에피소드 수 (전 시계열) vs T12 연도 합계 | T11 은 적합 구간(in-sample) 경보를 포함한다. T12 는 PURE/CARRY 마스크로 연도마다 자른다. 연말-연초 에피소드는 T12 에서 두 해에 각각 1건으로 셀 수 있다 (계약 K-3) |
| N-6 | 정책 B | T11 의 B 는 검정 구간 재귀를 2.3년 동안 끊지 않는다. T12 의 B 는 매년 1월에 재귀를 다시 시작한다. 재귀 표류의 크기가 구조적으로 다르다 |
| N-7 | T11 사건 근접 결과 | T12 에는 대응물이 없다 (금지) |
| N-8 | "T12 가 T11 을 재현/확인했다" 라는 서술 전반 | 설계가 달라 동일 귀무가 아니다. base 만 같은 계산이다 (P-1) |

## 4. 노트북·보고서 서술 규약

1. T11 결과를 기준선·정답·상한으로 쓰지 않는다. "T11 대비 개선/악화" 라는 표현을 쓰지 않는다.
2. base 연간 결과는 "T11 `yearly_blocks` 와 같은 계산 (일치 확인)" 으로 표시한다. T12 고유 결과로 세지 않는다.
3. T11 의 A 고정 모형 연도 블록과 T12 A 를 한 그림에 겹쳐 그리지 않는다. 그려야 한다면 T11 블록에 `IN_SAMPLE` 과 `OOS` 를 칸마다 표시한다.
4. 귀무 기대 경보는 단위(연율 / 연간 카운트)를 축 이름에 쓴다.
5. 2026 은 T11 에서는 검정 구간 일부, T12 에서는 `PARTIAL_NON_BLIND` fold 다. 둘 다 blind holdout 이 아니다.
