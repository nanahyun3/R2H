## §5 A-2 통계적 QA — 10개 질문

1. 연도별 training에 해당 연도 test 관측치가 유입되는가?
2. SVR/GARCH fit과 표준화 잔차 계산에 미래정보가 사용되는가?
3. 전체 연도를 대상으로 계산하는 사후 CUSUM을 온라인 경보처럼 취급하는가?
4. 각 연도의 표본 크기와 적합 기간이 검정 통계량의 분포에 어떤 영향을 주는가?
5. 기존 검정 임계값을 동일하게 사용할 수 있다는 근거는 무엇인가?
6. 분산 추정 방법 A/B/base가 size 및 power 왜곡과 어떤 관련이 있는가?
7. 검정 통계량의 정규화와 시계열 의존성이 결론에 영향을 주는가?
8. ETF 간 중복된 경제적 노출 때문에 집계 결과의 해석이 왜 제한되는가?
9. 2020년과 2026년의 높은 기각 수 차이가 시장 구조 때문이라고 말할 수 있는가?
10. 원논문 수치 재현 실패가 현재 T12 연구에 미치는 제약은 무엇인가?

기존 수치와 다른 결과가 나온 경우 원인을 분석하되, 원래 결과를 복원하기 위해 임계값이나 학습기간을 사후 튜닝하지 않는다.

## §6 B-2 진단 순서

비교 대상: 동일한 입력 CSV와 순서 · 동일한 fold 정의 · 동일한 seed · 동일한 Python 및 라이브러리 버전 · 동일한 모형·초모수 · 동일한 통계량과 판정 결과

1. CSV 행·열 정렬 및 인덱스
2. float 직렬화·파일 메타데이터
3. 결과의 전체 정밀도 차이
4. RNG·작업 순서·작업별 seed
5. NumPy/BLAS thread 및 최적화 구현
6. 병렬 작업에서 공유된 mutable state
7. 실제 모델 파라미터·통계량·기각 여부 변화

Byte Hash(저장 파일 sha256)와 Semantic Result Fingerprint(안정 정렬된 필드·타입·수치 내용)를 별도로 기록한다. 단순 반올림으로 차이를 감추지 않는다. 허용 오차가 필요하면 근거와 사용 조건을 명시하고, 기각 판정이 바뀌는 불일치는 반드시 실패로 처리한다.

## §5 A-4 독립 리뷰 체크리스트

- 표·그림의 숫자가 실제 계산값과 일치하는가?
- 기존 프로토콜과 수정된 방법이 섞여 있지 않은가?
- 수식·범례·단위·ETF 수·연도별 검정 기간이 정확한가?
- 사용된 임계값 및 통계량이 명확한가?
- 결과에서 허용되지 않는 인과·예측·조기경보 주장이 있는가?
- 2026 non-blind 조건이 모든 관련 결과에서 명시됐는가?

승인·반려·조건부 승인과 각 사유를 남긴다.

## §3 버전 분리

원래 프로토콜에 따른 재현은 `Original`, 수정한 방법론 검증은 `Corrected` 또는 `Sensitivity` 로 버전을 분리한다. 프로토콜이 수학적 정의와 충돌하면 임의로 수정하지 말고 충돌을 기록한다.
