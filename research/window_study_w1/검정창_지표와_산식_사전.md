# 검정창·지표·산식 사전 — W1

이 문서는 [사전 연구계약](../03_04_연구계약.md)의 용어를 독자가 확인할 수 있게 정리한다. 실제 수치는 실행 저장된 03·04 노트북과 `results/` CSV가 권위 있는 출처다. 본 연구는 T12의 사후 **분산** 구조변화 검정이며 ETF 가격 상승·온라인 매매 신호를 검정하지 않는다.

| 기호·열 | 정의·분모 | 주의 |
|---|---|---|
| `w` | 잔차 제곱 CUSUM의 이동 검정창 길이(20, 30, 60, 120; 252 탐색) | 변동성 기준선 `σ60`, proxy 길이 `m=5`, 부트스트랩 블록 `L=10`, CNN 입력 길이와 다름 |
| `e_t` | T12 정책별 표준화 잔차 `r_t/√v̂_t` | A·B·base의 `v̂_t` 생성 방식은 T12 `fit.py`를 그대로 사용 |
| `T_t(w)` | 창의 유효 잔차 n개에 대해 `max_k |∑_{i≤k}e_i²−(k/n)∑_{i≤n}e_i²|/(√n·√τ̂²)` | `τ̂²=n^{-1}∑e_i⁴−(n^{-1}∑e_i²)²`; 0 이하이면 계산 불가 |
| `PURE` | 검정연도 시작 이후 `t≥w−1`인 날짜 | `w=252`는 242–248일 연도에 한 날도 없으므로 결측이지 경보 0이 아님 |
| `common` | 후보 네 창 모두 PURE·유한인 `t≥119`의 날짜 교집합 | 합성 245일 연도는 126일; 실제 연도는 120~129일 범위, 잔차 결측 시 감소 가능 |
| `critical_annual_max` | 귀무 보정 반복의 `max_{t∈common} T_t(w)` 95% 표본 분위 | 검출기는 정규/t5/GARCH 중 최대, 적합 포함은 GARCH 정책별; T12 점별 임계값·원문 1.3397과 다름 |
| `any_alarm` | 귀무 평가 반복에서 공통기간 `T≥c`가 적어도 하루인 반복 비율 | H0 무변화 생성 경로에서만 연간 경보 확률/귀무 크기; 실제 ETF에서는 `경보있는 ETF·연도` 빈도일 뿐 |
| `detected_60d` | 생성 변화 시점 `k=122`부터 60거래일 이내 처음 경보가 있는 대립 반복 비율 | 합성의 60일 지평 검출률. 실제 ETF의 TP·precision이 아님 |
| `delay` | 검출된 H1 반복에서 첫 `alarm_at−k` 거래일 | 미검출은 검열, 중앙값/90분위는 **검출 조건부** |
| `episodes` | 경보일 사이 비경보 거래일이 최대 5일이면 하나의 묶음 | 하루 경보 수·연중 ≥1회 확률과 서로 다른 단위 |
| `episodes_per_252_valid_days` | 관측 에피소드 수 ×252/평가 가능 거래일 수 | 반복창의 연속성을 제거하지 않으며 오탐률이 아님 |
| `alarm_at` | 임계값을 처음 넘은 경보 거래일 종가 후 | 이날까지 자료로 계산 가능. 경보의 의미는 임계 초과이지 가격 급등 진실이 아님 |
| `estimated_change_at` | 경보 시점의 창 내부에서 CUSUM 편차가 최대인 `k̂` | **사후 위치 추정**. 가격 급등 시작 라벨이나 경보 발행 시각이 아님 |
| Wilson 상·하한 | 독립 반복의 이항 비율에 대한 95% Wilson 구간 | 사전 적격성의 H0은 상한 ≤0.10, H1은 하한 ≥0.15. ETF 간 독립구간으로 전용 금지 |

동일 `w`의 보정과 평가는 독립 시드 도메인을 사용한다. 한 반복 내 네 창은 같은 경로를 공유한다. 따라서 창 간 차이는 쌍대 구조로 읽되, 여러 창·정책·ETF의 동시 가족오류가 5%로 통제된다는 주장은 하지 않는다. 귀무 DGP가 실제 ETF와 일치하는지 검정하지 못한 이상 합성 크기 통과는 시장의 오탐률 보장이 아니다.
