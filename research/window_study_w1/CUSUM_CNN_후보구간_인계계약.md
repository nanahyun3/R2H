# CUSUM → CNN 후보구간 인계 계약

03·04의 `results/{03_real,04_real}/cnn_candidate_intervals.csv`는 **실제 분산 변화 정답 파일이 아니다**. T12 동결 잔차에서 W1 합성 GARCH 연간 최대 임계값을 적용해 관측된 에피소드의 첫 경보만 후보로 저장한다. 04 파일은 03의 4종을 포함하므로 두 CSV를 합쳐 중복 학습하지 않는다.

| 필드 | 뜻 | 이용 가능 시점·금지 해석 |
|---|---|---|
| `ticker,year,policy,w` | ETF·검정연도·T12 잔차 정책·CUSUM 창 길이 | `w`와 CNN 입력 길이를 동일시하지 않음 |
| `window_start,window_end` | 첫 경보가 평가한 잔차 창 범위 | 검정연도 내 PURE. 종가와 잔차가 가용한 범위만 |
| `alarm_at,available_at` | 최초 임계 초과 거래일과 해당 종가 이후 | 과거 시점으로 조기경보했다고 소급 금지 |
| `estimated_change_at` | `window_khat`의 창내 사후 최대편차 위치 | 독립 가격 라벨·실제 변동성 변화 정답으로 사용 금지 |
| `episode_last_alarm_at` | 5일 간격 규칙으로 묶인 마지막 경보일 | 미래 경보를 포함하는 사후 요약이며 첫 경보 시점에는 알 수 없음 |
| `threshold,T_at_alarm` | 선택된 합성 임계값·실측 T | 보정 귀무가 시장에 맞는다는 보장 없음 |
| `boundary_mode,candidate_reason` | `PURE_OOS_WINDOW_COMMON`·탐색 후보 표시 | 온라인 성능 또는 가격 급등 정답과 무관 |

CNN을 실제 급등 시작 탐지기로 평가하려면 (1) 다른 절차로 만든 독립 가격 급등 시작 라벨과 허용 시간차, (2) 미발생 구간·음성 사례 정의, (3) 온라인 정보 가용성의 시점별 차단, (4) 자산·기간별 블라인드 분리, (5) 사전 정한 오경보 비용·누락·지연 지표가 선행돼야 한다. 사후 선택한 CUSUM 후보를 정답으로 사용하면 순환 평가가 된다. 10/19 캡스톤의 20거래일 단순 탐지 baseline은 본 사후 분산 검정과 별도 과제다.
