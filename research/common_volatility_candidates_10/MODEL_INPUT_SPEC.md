# 10번 PART R — 급변 구간 라벨과 CNN·오토인코더 입력 명세 (`10-lock-2` 부록, 생성 전 고정)

설정 `configs/t19_model_input_v1.json`. 새 통계 검정이 아니라 **결과 인계 명세**다. 아래 선택(창 길이·피처·분할·지평)은 데이터셋을 만들기 전에 이 문서에 고정한다. 모델 성능은 이 노트북에서 평가하지 않는다.

## 1. 라벨 (정의별 급변 구간)

| 라벨 | 단위 | 정의 | 출처 |
|---|---|---|---|
| `A20` | ETF | 그 ETF 의 20일 σ 가 자기 과거 90분위 경계를 넘은 날 (09 의 ETF 단위 A) | 09 `daily_etf_states` |
| `C1` | 시장 | 17개 노출 그룹 중 같은 날 9개 이상 A (k*_fw = 9) | 10 lock-1 |
| `H2` | 시장 | 10 진입 · 8 유지 이력 구간 | 10 lock-2 |
| `WB` | 시장 | 자산군 균형 폭 ≥ 9/17 | 10 lock-2 |

- ETF 단위 구간: 20종 각각, A20 의 연속 거래일, 전체 달력에서 한 번에 추출, 기간 지위 태그 (2020 파일럿 · 2021–2025 주분석 · 2026 부분 비맹검). 2019 는 정의 불가.
- **사용 가능 시점**: t 종가로 만든 라벨·피처는 t+1 거래일부터 쓸 수 있다 (`available_from`).

## 2. 일별 피처 (채널, 모든 값은 t 종가까지의 정보)

| # | 이름 | 내용 | 비고 |
|---|---|---|---|
| 1 | `r` | 100·log(C_t/C_{t−1}) | |
| 2 | `abs_r` | |r| | |
| 3 | `sigma20` | 연환산 20일 σ (%) | |
| 4 | `sigma60` | 연환산 60일 σ (%) | |
| 5 | `ratio20` | σ20 / 급변 경계 b20 | **A20 을 직접 결정** — 같은 날 A20 탐지 과제에서는 제외 |
| 6 | `U20` | σ20 의 엄밀 과거 mid-rank 분위 | **A20 을 직접 결정** — 동일 |
| 7 | `U60` | σ60 분위 | |
| 8 | `peer_L` | log(σ20 / Peer 중앙 σ20) (09) | Peer 상대 괴리 |
| 9 | `peer_UB` | peer_L 의 과거 분위 (09) | |
| 10 | `breadth` | N_A(q20) / 17 (시장 공통 폭) | **C1 을 직접 결정** — C1 탐지 과제에서는 제외 |
| 11 | `intensity` | I = Σ_g max(σ/경계 − 1, 0) (시장) | 이상값 민감 (153130 2024-01) |
| 12 | `cusum_R` | W3 SVR–GARCH CUSUM, 12셀 최대 T/crit_w3 | 6종·2021–2025 만, 없으면 0 |
| 13 | `cusum_mask` | cusum_R 이 정의되면 1, 아니면 0 | |

결측은 0 으로 채우되 해당 날짜의 채널 결측 여부를 `nan_mask` (창 × 피처) 로 함께 저장한다.

## 3. 표본 (창)

- **창 길이 W = 60 거래일**, 창 끝 t 를 포함.
- **D1 슬라이딩 (CNN 예측)**: 모든 (ETF, t), t ∈ 2021-01-04 … 2026-10-02, 창 [t−59, t]. 라벨
  - `y_next5_A20` = (t+1 … t+5) 중 A20 이 하루라도 1 (주 과제 — 미래 급변 조기 경보)
  - `y_A20_t`, `y_C1_t`, `y_next5_C1` (보조)
  - 마지막 5거래일은 미래 라벨이 없어 `y_next5_*` = NA.
- **D2 사건 정렬 (CNN 분류·설명)**: ETF 급변 구간마다 창 [start−40, start+19] (시작일이 41번째 칸). 라벨 = 구간 ID·유형 (단일 충격/누적).
- **D3 정상 창 (오토인코더)**: 창 안에 A20 이 하루도 없고 창 끝 다음 5일에도 A20 이 없는 창, 보폭 5일. 학습은 정상 창만, 평가에서 D1 의 양성 창에 재구성 오차를 비교.

## 4. 분할 · 누수 방지

- 창 끝 t 기준: **train ≤ 2023-12-29 · val 2024 · test 2025 · holdout 2026 (비맹검, 별도 보고)**.
- 분할 경계 앞 5거래일(라벨 지평)은 `embargo` 로 표시하고 학습·평가에서 뺀다.
- 정규화: ETF·피처별 평균·표준편차를 **train 창의 끝 날짜 값들만으로** 계산해 `normalization.json` 에 저장한다. 모든 분할에 같은 값을 적용한다.
- 경계 σ·분위는 엄밀 과거만 쓴다 (09). 시장 피처(`breadth`·`intensity`)도 t 까지의 정보다.
