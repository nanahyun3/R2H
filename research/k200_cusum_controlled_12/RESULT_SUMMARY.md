## 핵심 결과
1. **B0↔B1**: 둘 다 유효한 날 T 동일, B1 유효일 +295 → 연초 초기화는 커버리지만 바꾼다 (`COVERAGE_GAIN`). 관측 경보(α=0.05) B1 43일 — 전부 2020, 2021–2025 0일.
2. **창**: 짧은 창은 같은 α 에서 지속형 변화 검출 손실. w252 의 2021 경보 159일은 COVID 이월 63 + 잔차 분산 감소 96 (X-D7 기억 채널).
3. **공식**: Page 상방은 정책 A 잔차 척도(연평균 e² 0.95–3.33) 때문에 h≈57 — 그대로 쓸 수 없음. X1 자기정규화 Page 가 하루 극단 검출 0.325 → 0.640 (탐색적).
4. **변화점 초기화**: 관측 위약 대비 우위 없음 (9/102·8/102). 합성에서 이동 CoS 는 손실, Page 는 누적 편향 제거로 하루 극단 이득.
5. **SVR**: QLIKE 이득은 2020 한 해에 몰림 (2021–2025 는 1.393–1.402 로 동일), 직전 252일 학습은 나쁨 (1.525). 유예 재학습은 경계 단절로 구현 기원 경보 27·26일 (X-D6).
6. **보정**: 같은 통계량에서 귀무 선택만으로 홀드아웃 오경보율 0.012–0.195. N1 은 0.060 (±1–1.5%p 공통 요동, X-D5).
7. **검출력**: 지속형 분산 변화(×1.5–×3·점진·장기·반복·연말)는 **모든 탐지기 크기 수준** → `LOW_POWER_INCONCLUSIVE`. 크기와 구별: 하루 극단(Page 계열)·분산 감소(Page 하방 0.085).

## 연구 질문에 대한 답
KODEX 200 에서 **연도 관통 이동 CoS(여러 창) · 원수익률 CoS · Page 하방 · 자기정규화 Page · 변화점 점수(M·P·V·K) · 예측분산**은 서로 중복이 낮고 일부(긴 창 CoS 0.052, M20_60 0.043, Page 하방 0.037 증분 R²)는 미래 변동성에 추가 정보를 준다 → **연속형 AE 입력으로 넘길 가치가 있다.** 그러나 어떤 CUSUM 구조·SVR 정책도 현실적 군집 귀무에서 지속형 분산 변화를 크기 이상으로 검출하지 못했으므로, **경보·유의성은 급변 라벨로 넘기지 않는다.** 정책 A SVR 이 변화를 예측분산으로 흡수하는 것이 주원인이다.
