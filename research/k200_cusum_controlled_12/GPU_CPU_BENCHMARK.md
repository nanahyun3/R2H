## 권고

- 이동창 CoS 대량 경로 (귀무 MC 임계값·블록 최대): GPU float64 사용 — 속도비 7.7×–28.1×
- Page h 격자 K=1: 블록집계 속도비 0.3× / 격자 0.2× → CPU 사용
- Page h 격자 K=64: 블록집계 속도비 11.2× / 격자 6.9× → GPU
- Page h 격자 K=256: 블록집계 속도비 41.9× / 격자 14.5× → GPU
- Page h 이분 탐색 (`calibrate_page_h`) 은 K 후보 격자 `page_block_hits` 한 번으로 바꾸면 GPU 이득이 크다 (단 K≥64)
- float32 는 사용 금지 (경보 뒤집힘 관측)
- Page·블록 집계는 CPU 와 비트 일치, 이동창 T 는 비트 일치가 아님 (최대 절대오차 ~1e-14) — 임계값과 T 는 같은 backend 에서 계산할 것
- GPU 는 동시에 한 작업만 — 다른 세션과 겹치면 예산 min(6 GB, 여유−2 GB) 가 줄어 chunk 가 작아진다

- 전체 최대 VRAM (torch max_memory_allocated): 3460 MiB
