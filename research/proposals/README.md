# 후속 연구 제안 (구현·성과 없음)

이 폴더의 항목은 **아이디어 단계**다. 코드·실험·성과가 없으며 CUSUM 기준선의 완료 상태와 섞지 않는다.

| 제안 | 분리해 둘 것 | 상태 |
|---|---|---|
| HMM 상태추론 | 잠재상태 / 관측 / 정답 가격 사건 / 정책을 별개로 정의 | 미착수 (10/09 세미나 발표만) |
| Active Inference (Friston) | 생성모형·선호·정책 선택을 탐지 계약과 별도 층으로 | 미착수 |
| Dynamic Programming 기반 진입·청산 | 백테스트 계약(`r2h.backtest`) 위의 정책 | 미착수 |
| 4조 PELT 사후 구간 분할 | `mode="posthoc"` 로만 비교 | 4조 담당 |
