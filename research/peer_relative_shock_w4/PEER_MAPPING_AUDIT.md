# W4 Peer Mapping 감사

동결 계약: `PEER_MAPPING_CONTRACT.md` (W4-lock-1, 커밋 `52f98b0`). 이 감사 문서의 진단 수치는 모두 **동결 이후** 계산했다. 매핑을 바꾸는 데 쓰지 않았다.

## 1. 선정 과정에서 본 것과 보지 않은 것

| 단계 | 본 것 | 선정에 쓴 것 |

| 후보 탐색 | 상장 스냅샷 종목명·기초지수명, 시가총액 열(스냅샷 2026-10-03) | 종목명·기초지수명 |
| 가격 수집 | FDR 0.9.202 일봉 51종 (2019-01-02 ~ 2026-10-02), 첫 관측일 | 첫 관측일 (상장 cutoff 2019-06-30) |
| 수집 직후 품질 훑기 | 후보·평가 ETF 의 거래량 0일 수, 무변동(수익률 0)일 비율 | **쓰지 않음** — 단기채(153130 16.8%, 157450 20.0% 등)의 무변동일이 많다는 사실만 기록 |

## 3. 사후 진단 (`results/peer_mapping_quality.csv`, 주분석 2021–2025, q=20)

| 진단 | A·B 등급 (동일 지수) | C 등급 (유사 위험) |
|---|---|---|
| 자기 σ 와 Peer 중앙값의 Spearman | 0.940 (192090) – 0.999 (069500) | 0.525 (117680) – 0.954 (148070) |
| 로그비율 L 표준편차 | 0.015 – 0.100 | 0.090 – 0.445 (153130) |
| 유효 Peer 수 최소 (주분석) | Tier 1 ≥ 1 충족 | Tier 2 ≥ 2 충족 |

해석:
- 동일 지수 쌍의 B 는 추적 차이·호가 단위·유동성 차이가 평소보다 커진 상태다. 시장 충격의 직접 측정이 아니다.
- 업종 대 시장(091180·117680)은 업종 σ 가 시장 σ 보다 대부분 위에 있다 (주분석 L > 0 인 날 94.5%·96.1%). B 는 그 간격의 이례적 변화다.
- 148070 은 Peer 듀레이션이 짧다. 2022 에는 A∧B↓ 가 28일이었다. 짧은 만기 Peer 의 변동성이 평소 비율보다 더 크게 올랐다는 뜻이다.
- 261220 의 둘째 Peer 219390 은 원유 생산기업 주식이다. Peer 중앙값은 두 값의 평균이므로 주식 변동성이 절반을 차지한다.
- 133690·219480 은 서로를 Peer 로 쓰므로 두 ETF 의 B 는 독립이 아니다.

## 5. 판정에 미친 영향

주분석 2021–2025 의 1,225일 모두에서 17개 그룹의 A·B 가 평가 가능했다. 따라서 Peer 부족이 판정을 막은 날은 없다. `INSUFFICIENT_PEER_COVERAGE` 가 아니라 `VALID_ZERO_INTERVALS` 로 판정한 근거가 이것이다.

## 6. 지시서 Tier 용어와의 대응

| 지시서 | 이 연구 | 해당 Peer |
|---|---|---|
| Tier 1 — 동일 기초지수 | Tier 1 (동일 지수 계열) | 31개 연결 |
| Tier 2 — 유사 기초위험 | Tier 2 (유사 위험) | 24개 연결 |
| Tier 3 — 20종 안에 Peer 가 없을 때의 외부 참조자산 | 별도 등급 없음. `peer_in_eval20 = False` 로 표시 | 채택 42종 중 38종 (20종 안 Peer 는 069500·102110·133690·219480 4종) |
| Tier 4 — 비교 불능 | `PEER_UNAVAILABLE` | 0 |

- 이 연구의 Tier 는 **경제적 근접도**(동일 지수 대 유사 위험) 기준이다. 지시서의 Tier 3 은 **출처**(20종 밖) 기준이다.
- 따라서 지시서 기준으로는 외부 참조자산 38종이 모두 Tier 3 성격이다. 이들은 평가 20종과 같은 출처(FDR 0.9.202)의 KRX 상장 ETF 이고, 원자료와 같은 거래일·통화(KRW)·수정주가 처리를 쓴다.
- 동결 계약(W4-lock-1)의 용어는 바꾸지 않았다.
