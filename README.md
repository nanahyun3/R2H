# R2H
주가 급등 국면 포착 에이전트 (2026.9~2027.6, 홍익대학교 졸업 프로젝트)

## 장기 보유를 이길 수 있는가 — 언제 사고 언제 팔 것인가 (중간 연구 보고)

국내 상장 ETF 20종의 일봉만으로 **언제 사고 언제 팔지** 를 정하는 규칙이 장기 보유(Buy & Hold)를 이길 수 있는지를 검증했다.
이 브랜치는 증권사 실무진에게 자문을 요청하기 위한 A4 보고서(md · docx · pdf), 보고서의 모든 숫자를 처음부터 다시 계산하는 노트북, 입력 자료와 결과 표 · 그림을 담는다.
보고서는 자체 검토로 효과가 확인되지 않은 대안을 걸러 내고, 실무 판단이 필요한 쟁점만 질의 사항으로 정리했다.

| 항목 | 값 |
|---|---|
| 질문 | 20일 신고가 돌파 매수 · 20일선 또는 3 ATR 이탈 매도 규칙이 장기 보유를 이기는가 |
| 답 | **총수익은 보유 열위** (+61.9% vs +90.2%) · 샤프(0.94 vs 0.62)와 최대낙폭(11.6% vs 31.3%)은 점추정 우위이나 대부분 노출 축소(평균 노출 38%) 효과 · **같은 변동성 보유+현금 대비 초과수익** 연 +3.0%p [−1.7, +8.3] 은 통계적으로 유의하지 않음 |
| 종목 | 국내 상장 ETF 20종 (17개 기초지수군) — 레버리지 · 인버스 제외 |
| 자료 | FinanceDataReader 일봉, 2017-01-02 ~ 2026-10-29 (`data/etf_daily_20261101.csv`, SHA-256 `54511b71f93a3c7b…`) |
| 평가 기간 | 2021-01-04 ~ 2026-10-29 (약 5.8년). 그 이전은 학습 · 지표 계산에만 사용 |
| 체결 · 비용 | 종가로 판단하고 **다음 날 시가에 체결** · 거래비용 편도 0.1% · 현금 이자 0 · 세전 |
| 포트폴리오 | 기초지수군마다 같은 비중 (같은 시장을 추종하는 ETF 를 여러 번 세지 않음) |
| 모델 | 그래디언트 부스팅(GBM), 기술적 지표 13개, 매년 과거 자료로만 재학습 (학습 · 평가 사이 60거래일 공백) |
| 통계 | 분기 단위 블록 부트스트랩 95% 신뢰구간 · 조건 맞춤 무작위 매수 1,000회 · 핵심 검정 4개 Holm 보정 |

## 2. 핵심 결과

### 2.1 장기 보유와 비교 (20종 · 지수군 동일 비중 · 시가 체결 · 편도 0.1%)

| 전략 | 누적 수익 | 최대낙폭 | 샤프 비율 |
|---|---|---|---|
| 매수 후 보유 | +90.2% | 31.3% | 0.62 |
| 절반 보유 + 절반 규칙 | +76.0% | 23.1% | 0.74 |
| 200일선 추세 추종 | +70.1% | 27.6% | 0.64 |
| GBM 모델(통합 학습) + 같은 매도 규칙 | +62.3% | 17.3% | 0.85 |
| **20일 신고가 돌파 규칙** | **+61.9%** | **11.6%** | **0.94** |
| 같은 변동성의 보유+현금 (보유 43%) | +36.5% | 14.2% | 0.62 |

규칙은 평균 38% 의 기간만 주식을 들고 있었다. 현금 구간에서 놓친 상승(+1.08)과 피한 하락(−1.13, 로그 수익 · 종목 평균)은 거의 상쇄되었고,
보유에 뒤진 몫은 크게 오른 소수 종목을 덜 들고 있었던 데서 나왔다.

### 2.2 검토한 대안과 판단

| 대안 | 근거 |
|---|---|
| ① 매수 시점 고도화 — GBM 으로 상승 구간 예측 (제외) | 상승 구간 라벨 AUC 0.816 · 거래 성공 라벨 AUC 0.515. 실제 매수의 거래 성공률(52.2%)은 조건 맞춤 무작위 매수(52.3%)와 같음. 수익 나는 날을 직접 학습해도 AUC 0.484 |
| ② 고점 근처 매수 회피 (제외) | 상승 구간을 맞힌 매수 501건 중 고점 3거래일 이내 매수 61건은 이익 거래 2%. 고점 직전 매수 61건 중 과열 지표에 걸린 것은 6건(10%) |
| ③ 매도 규칙 변경 (현행 유지) | 20일선 매도 제거 시 샤프 −0.11 [−0.38, +0.13]. 대안 넷 모두 기본 규칙보다 낫다는 근거 없음 |
| ④ 재진입 조건 변경 (현행 유지) | 20일선 회복 재진입의 41% 가 2거래일 안 재청산(휩소) vs 20일 신고가 재진입 5% |

### 2.3 핵심 검정 (Holm 보정)

| 검정 | 효과 | Holm 보정 p |
|---|---|---|
| 보유 대비 타이밍 가치 (같은 변동성 보유+현금 대비) | 연 +3.0%p [−1.7, +8.3] | 0.71 |
| 매도 시점의 가치 (같은 보유 기간 무작위 매도 대비) | 연 +3.1%p | 0.48 |
| 20일선 매도 제거 | 샤프 −0.11 [−0.38, +0.13] | 0.71 |
| 과열 지표의 고점 직전 판별력 | AUC 0.689 (섞은 경로 중앙값 0.702) | 0.78 |

넷 모두 통계적으로 유의하지 않다. 이 표본으로 가려낼 수 있는 최소 차이는 연 7~9%p 수준이다 — '차이가 없다' 가 아니라 '이 기간으로는 가릴 수 없다'.

## 4. 재현

```bash
# Python 3.12 · numpy · pandas 3 · scikit-learn 1.9 · scipy · matplotlib · pyarrow · nbconvert
REPORT_ROOT=$PWD OMP_NUM_THREADS=4 jupyter nbconvert --to notebook --execute 1107_중간연구보고.ipynb --output 1107_중간연구보고.ipynb
python src/write_report.py      # md · pdf · docx 재생성 (pdf 는 playwright Chromium, docx 는 pypandoc 필요)
```

- 노트북 첫 셀이 입력 파일의 SHA-256 을 확인하고, 다르면 멈춘다
- GBM 은 `early_stopping=False` · 행 순서 고정 · 시드 0 으로 학습해 실행할 때마다 같은 값이 나온다 (기본값 `'auto'` 는 학습 행이 1만 개를 넘으면 켜져 행 순서 · 시드에 따라 결과가 흔들린다)
- 가격 순서를 섞은 경로(200~400개) · 대조 모델 학습은 `results/cache/` 에 저장된다. 처음 실행은 수십 분, 이후는 몇 분
- 코어가 많은 PC 에서는 `OMP_NUM_THREADS=4` 를 주지 않으면 GBM 학습이 매우 느려질 수 있다

## 5. 계산 점검 (노트북 안에서 자동)

| 점검 | 결과 |
|---|---|
| 거래별 손익의 곱 = 시가 체결 누적 수익 | 최대 오차 1e-14 수준 |
| 재진입 체결이 모두 판단일 다음 날 시가인가 · 자료를 중간에 잘라도 과거 매매가 같은가 | 위반 0 · 불일치 0 |
| 거래 성공 라벨의 벡터 계산 = 하루씩 따라간 계산 | 불일치 0 |
| 학습 마지막 날의 라벨이 평가 시작 전에 확정되는가 | 확정 |
| 보유 대비 격차의 분해 항등식 | 오차 < 1e-9 |

## 6. 한계

- 평가 기간 5.8년 · 같은 시장을 따르는 ETF 가 많아 사실상 독립적인 시장은 몇 개뿐이다
- 2021년 이후 자료는 연구 과정에서 여러 번 보았으므로 완전한 표본 외 검증은 아니다
- 상승 구간과 고점 위치는 사후에만 확정된다 — 진단에만 쓰고 매매 신호에는 쓰지 않았다
- 세전 · 현금 이자 0 · 슬리피지는 편도 0.1% 비용에 포함한 가정이다
- 과거 성과는 미래 수익을 보장하지 않으며, 이 자료는 투자 권유가 아니다
